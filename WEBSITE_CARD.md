## Title

VBA Certificate Generator

## Short description

A small Windows GUI tool for creating a self-signed VBA code-signing certificate for Excel / Word macro projects.

## Tags

VBA, Excel, Code signing, Certificate, Windows

## Long description

This tool creates a self-signed code-signing certificate for VBA macro projects. It exports `.pfx` and `.cer` files and is intended for personal or internal-company VBA tools. It is useful when developing Excel / Word macro-enabled files and preparing them for safer internal distribution.
